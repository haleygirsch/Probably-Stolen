Probably Stolen — customer sprite PNGs

The updated project includes transparent PNG portraits supplied by the user in customers.zip, with transparent padding trimmed for larger portraits. The gallery is filterable by sprite group .

Original uploaded filenames and their normalized assets are documented in:
  src/main/webapp/assets/customers-portrait-manifest.json

Named character portraits are separated from generic sprite pools. A pool sprite can represent multiple possible visitors and does not guarantee that a customer has that appearance in every encounter.

See tools/customer-notes.md for how to edit customer records.
