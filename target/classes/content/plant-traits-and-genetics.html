The DNA Manipulator can extract trait discs, install traits, and alter seeds across generations. The main rhythm: edit once, grow the seed, then edit its offspring.

Gene editing in four steps

  1. Unlock Plant Genetics, obtain the DNA Manipulator and Gene Scanner.
  2. Put a seed in the target slot and a blank DNA Data Disk in the blank-disk slot to extract a random trait. A Genetic Stabilizer Module lets the seed survive extraction.
  3. Install a written trait disc on a target seed using the trait-disk slot.
  4. Grow the edited seed before editing again to clear temporary heat. Offspring retain permanent edits.

Understanding success rates

The supplied tutorial uses a base chance of 95%, reduced by 5 percentage points per complexity/heat point. More edits make future edits harder. Use the Manipulator tooltip to read its actual chance before committing.

Example: faster Kotton

Extract the Slow Grower trait from stock Kotton (ideally using the Negative Trait Filter). Then obtain Fast Grower from a suitable source such as Fillerweed, install it, grow the new seed, and repeat to raise its trait rank. Use fresh seeds and filtered extraction to avoid unnecessary heat.

Helpful modules

Genetic Stabilizer preserves a seed during extraction. Positive and Negative Trait Filters reduce the trait pool; Quality modules raise the success chance.

Playing tips

  • Each install attempt can generate heat whether it succeeds or fails; fresh harvested seeds are used to reset this accumulated burden.
  • The Gene Scanner reveals trait ranks, complexity and heat before you commit precious disks.
