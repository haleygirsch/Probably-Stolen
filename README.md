# Probably Stolen — Pink Handbook (Maven)

Java 17+ local website with 51 tabs across 8 categories. Content remains placeholder HTML. Maven packages an executable JAR using the built-in Java HTTP server (no servlet container required).

## Layout
- `src/main/java`: Java packages and application classes.
- `src/main/resources`: application resources (reserved for future configuration/data).
- `src/main/webapp/assets`: CSS and JavaScript.
- `src/main/webapp/content`: 51 page fragments.
- `src/test/java`: four test suites and AllTests runner.
- `src/test/resources`: reserved for test fixtures.
- `target`: generated by Maven; never commit it.

The POM explicitly copies webapp files onto the classpath because this project is an executable JAR rather than a servlet WAR. Optional Maven directories (filters, it, assembly, site) are omitted until needed.

## Eclipse
File > Import > Maven > Existing Maven Projects. Select the extracted folder containing pom.xml and Finish. Use JDK 17 or newer. Right-click the project > Run As > Maven test to execute tests, or Run As > Maven build with goals `clean package`. Run Main as a Java Application after Maven resources have been built, or run the JAR from terminal. If assets are missing in Eclipse, run Maven package and launch the JAR.

## Terminal
Install Maven and JDK 17+. Run `mvn clean test`, then `mvn package`, then `java -jar target/probably-stolen-wiki-1.0.0.jar`. Open http://localhost:8080/. Optional port argument: `8081`. Maven needs access to download plugins initially.

## Add content
Edit the appropriate HTML fragment in src/main/webapp/content, then rebuild and restart. Edit assets/style.css for theme and assets/app.js for frontend behavior. The original Java packages and sidebar are unchanged.

## Tests
Maven test phase invokes AllTests through exec-maven-plugin. Tests use explicit checks and run without Java VM option `-ea`; no JUnit dependency is required. The test suite checks navigation, resources, view and HTTP routes.

## IntelliJ IDEA (macOS)
1. Open the folder containing `pom.xml` as a Maven project. Set the Project SDK to JDK 17 or newer.
2. Expand `src/test/java/com/probablystolen/AllTests.java`, right-click its `main` method, and select **Run 'AllTests.main()'**. You do not need `-ea`.
3. To run the website, right-click `src/main/java/com/probablystolen/Main.java` and select **Run 'Main.main()'**. Open http://localhost:8080/. If CSS or pages are missing when running directly, run `mvn package`, then launch the JAR to ensure `src/main/webapp` resources are on the classpath.
4. From IntelliJ Terminal, `mvn clean test` executes the same four test suites; `mvn clean package` builds the executable JAR.
